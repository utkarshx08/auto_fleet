# Autrail — Fleet Command Dashboard

A responsive dark fleet-management dashboard inspired by the supplied reference image.

## Run locally
No build step or package installation is required.

1. Extract the ZIP.
2. Open `index.html` in a browser.

For a local dev server, run:
```bash
python -m http.server 5500
```
Then visit `http://localhost:5500`.

## Included interactions
- Search/filter the visible vehicle table.
- Switch the distance chart between week, month, and year views.
- Export a sample fleet report as CSV.
- Navigation, action buttons, and notification feedback.
- Responsive layout for desktop, tablet, and mobile.

## Customization
Edit `styles.css` for theme/layout, `script.js` for interactions, and `index.html` for dashboard content.

The sample fleet records and metrics are demo data. Connect your own API/database before using this as a live fleet-management system.
